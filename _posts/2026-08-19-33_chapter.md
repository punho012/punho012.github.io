## Phile 33. Open-source software

Open-source software is software whose source code is publicly available for anyone to inspect, study, modify and redistribute depending on the software's license.
Available source-code provide a greater transparency and verifiability. Security researchers and experts can review the code, identify potential vulnerabilities and investigate how it handles ssensitive data. 
This is essential from a privacy perspective. By examining the source code, researchers can investigate whether an application collects unnecessary data or implements unexpected functionality.
However, it is important to mention here that open source does not automatically mean secure, private or trustworthy. Open-source projects are not immune to vulnerabilities. No software can guarantee perfect security, regardless of whether its source code is public or proprietary. The important difference is that open-source provides the opportunity of independent verification.
In open-source software researchers can verify the security patches and inspect how vulnerabilities were addressed. This creates an additional layer of transparency that is generally not available when the source code cannot be independently inspected.
Another major advatnage of open-source software is the ability to modify and self-host the code which can give users a greater control over their data and infrastructire. This can be extremely valuable from an OPSEC point of view beacuse users do not have rely on a third-party service provider.

### Transparency Is Not the Same as Trust

Open-source software can reduce the amount of blind trust required, but it cannot eliminate trust completely.
We still need to consider questions such as:

- Who maintains the project?
- How active is the development?
- Has the code been independently audited?
- How are vulnerabilities handled?
- Are dependencies trustworthy?
- Are official builds reproducible?
- Can the distributed binaries be verified against the published source code?
- Who controls the infrastructure if the software is provided as a service?

This brings us back to the previous chapter.

### Final takeaway
Open-source software can improve transparency, enable independent review, and reduce the amount of blind trust placed in a software vendor. But open source is not a guarantee of security or privacy; its real value is that it makes independent verification possible. From an OPSEC perspective, this can help reduce external dependencies and give users greater control over the software and data they rely on. Ultimately, open source does not remove the need for trust — it gives us more opportunities to verify it.
