## Phile 34. Metadata

Metadata is data about data. Simply put: metadata provides information about your online activities. Almost every digital action and service creates metadata including email, messaging applications, photos, websites, online accounts. 
That is why it is essential to protect metadata just as we protect the content itself. Even if the content of the communication is encrypted, the metadata may still reveal information about the communication and the people involved.  The amount and type of metadata collection depends heavily on the service and its configuration. Some providers minimalize metadata collection while others may retain significant amount of it. 
Some examples of metadata include:
- Who: sender, recipient
- When: timestamp, duration of the interaction
- Where: IP address, GPS location
- What: subject, filename of an attachment
- How: device and browser fingerprint, device type, operating system, version
- Size: message length, size of the attachments

If an adversary collects enough metadata it can potentially be used to identify and deanonimyze an individual. Metadata can reveal relationships, routines, locations, pattern of behaviours even without access to the actual content. There are documeted cases where investigators used metadata as evidence to identify suspects.

### How to deal with metadata?
There are several actions we can take to reduce metadata exposure. First we should consider providers that minimize the collection and retention of metadata. Even if any data is collected, there must be minimal data retention.
Another mitigation technique is using the Tor browser when accessing websites. It makes the website unable to uniquely identify users based on metadata like IP address or browser fingerprint.
There are also tools that can help remove metadata from files. These can be used to strip metadata from documents, photos, videos, and other files before sharing them.

### Final takeaway
Metadata is often an underrated element of privacy and OPSEC. Protecting the content of a communication is important, but the surrounding metadata can reveal valuable information as well. Where possible, minimizing the collection, retention, and unnecessary exposure of metadata should be part of a broader OPSEC strategy.
